# DSH 工具与插件手记

这份东西分两组：**通用**那一组换任何项目都照用；**DSH 内核**那一组讲 DeepSeek Harness 的插件层，
换个宿主就不成立。两组故意分开放，为的是打开目录一眼能看出「这里面有 DSH 的内容」。

> 这是 `manual/` 目录的索引。仓库根目录的 `README.md` 是另一份东西，未作改动。

## 三、你该读哪册

- 只想把命令在这台机器上跑对 → 通用 **1**
- 要往 GitHub 推东西，或者想弄清 API 与 git 的分工 → 通用 **2**
- 连不上，或者时通时不通 → 通用 **3**
- 装了没效果、卡住、查不出原因 → 先通用 **4**，再看 DSH **1**
- 在写 DSH 插件 → DSH **1 → 2 → 3**
- 要把插件发出去 → DSH **4**

拿不准先读通用第 4 册，它讲的是怎么定位，不假设你卡在哪一层。
