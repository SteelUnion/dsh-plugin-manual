## 一条主线

四册其实是同一个问题的四个面：**插件没反应的时候，故障在哪一层。**

- 钩子根本没被调用 → 1
- 钩子调用了但返回的东西没被接受 → 1
- 插件想读服务但没声明 `inject` → 3
- 插件装了，但版本范围把它挡在门外 → 2
- 这些都对了，发出去的包却和本地不一致 → 4

按这个顺序查，不要跳。第 1 册里那张「四行表」是入口：连模块加载记录都没有、有记录没
`apply()`、有 `apply()` 钩子没触发、钩子触发了但行为不对——四种情形对应四种查法。
